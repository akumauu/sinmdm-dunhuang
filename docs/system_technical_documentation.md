# 敦煌舞三维动作生成系统 - 技术开发文档

## 1. 系统概述
本系统基于 **SinMDM (Single Motion Diffusion Model)** 框架，旨在通过单条敦煌舞三维动作数据（BVH格式）训练出一个能够生成无限、多样且风格一致动作的生成式模型。系统结合了最新的 **扩散模型 (Diffusion Model)** 与 **QnA (Query-and-Attention) 架构**，针对中国传统舞蹈（敦煌舞）的复杂姿态进行了深度优化。

---

## 2. 核心技术框架

### 2.1 扩散模型 (Diffusion Model)
本系统采用高斯扩散过程作为核心生成算法：
- **前向过程 (Forward Process)**：在原始动作数据中逐步加入噪声，直到其变成纯高斯噪声。
- **反向过程 (Reverse Process)**：训练神经网络（MDM）学习如何根据当前加噪状态和步数 $t$ 预测并去除噪声，从而从随机噪声中恢复出流畅的动作。

### 2.2 QnA Net 架构
不同于传统的 Transformer，本系统采用了 **QnA (Query-and-Attention)** 架构：
- **分层特征提取**：通过类似卷积的局部注意力机制，更有效地捕捉人体骨骼的时空局部特征。
- **计算效率**：在处理长序列动作数据时相比标准 Attention 具有更高的效率和更好的泛化能力（特别是在单样本数据集上）。

## 3. 系统模块详解

### 🛒 3.1 数据处理模块 (`data_utils/`)
- **`bvh_general` 支持**：系统原生支持直接加载 BVH 文件。它会自动解析骨骼层级，并将关节旋转角度转换为 **6D 旋转表示 (6D Rotation Representation)**，相比四元数或欧拉角，其连续性更强，更利于神经网络训练。
- **归一化处理**：通过对动作进行减均值和缩放，保证输入数据分布在网络易于学习的区间。

### 🧠 3.2 模型实现模块 (`models/`)
- **`QnAMDM` 类**：模型的主体入口，负责将输入动作向量映射到潜空间（Latent Space）并结合时间步（Time Step）进行计算。
- **`input_proj` / `output_proj`**：根据输入动作的**关节数**和**特征维度**动态调整投影层，实现了对不同骨骼定义的数据集（如敦煌舞数据与 HumanML3D 数据）的完美兼容。

### ⚙️ 3.3 训练管线模块 (`train/` & `diffusion/`)
- **损失函数**：主要采用 MSE Loss 衡量预测值与真实值之间的差异。
- **学习率策略**：采用了 `ExponentialLR` 指数衰减策略，在训练后期通过更小的学习率确保模型能够捕捉微小的舞蹈细节并稳定收敛。

### 🛠️ 3.4 辅助工具模块 (`dunhuang_dance_gen/`)
- **可视化**：可将生成的 6D 向量数据反向映射回 3D 骨骼空间，并导出为标准的 BVH 格式，供 Blender、Unity 等 3D 软件编辑。
- **后处理**：包含平滑滤波器，用于消除生成过程中可能出现的微小抖动（鬼畜）。

---

## 4. 关键技术修复与优化
在本项目开发过程中，针对敦煌舞特有的 **198 特征维数** 进行了以下核心修复：
1.  **动态维度匹配**：彻底解决了原框架硬编码 263 维导致的维度冲突问题。
2.  **BVH 直传模式**：避开了繁琐且易出错的多步预处理，实现了单文件即入即练。
3.  **过拟合监控**：在训练约 6000-8000 步时达到平衡点，有效防止了深度训练导致的“关节扭曲”现象。

## 6. 使用建议 (针对毕设评估)
- **训练建议**：对于单段舞蹈，建议步数控制在 8000 步以内。
- **评估指标**：建议使用“风格多样性”与“动作流畅度”进行定性评价，以及通过 Blender 观察关节重叠（Collision Check）进行定量分析。
