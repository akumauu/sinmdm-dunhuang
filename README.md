# 敦煌舞三维动作生成系统 (轻量化版本)

本仓库包含了针对敦煌舞三维动作生成的定制化代码、数据集样本及训练结果。为了保持仓库简洁并专注于核心贡献，本版本去除了 SinMDM 的原始未修改文件，仅包含核心修改部分和辅助工具。

## 📁 仓库结构

- **`core_modifications/`**: 针对 SinMDM 框架进行的深度定制与修复代码。
  - `train/train_sinmdm.py`: 优化了训练参数保存逻辑，支持关节数自动记录。
  - `sample/generate.py`: 增加了从检查点自动推断动作维度的功能，解决了推理冲突。
  - `utils/model_util.py`: **关键修复**：移除了硬编码的 263 维限制，支持动态适配敦煌舞的 198 维特征。
  - `data_utils/`: 增强了对 `bvh_general` 模式的支持。
- **`dunhuang_dance_gen/`**: 完整的辅助脚本包，包含：
  - `visualize/`: 三维动作可视化工具。
  - `scripts/`: 数据测试与预处理演示脚本。
- **`dataset/`**: **源数据**。包含本次训练使用的原始 BVH 文件：`01-HuiShenCeTuoShi.bvh`。
- **`checkpoints/`**: 精选模型。包含 Step 6000 和 Step 8000 的最佳权重（效果最流畅，无过拟合）。
- **`docs/`**: 完整的技术文档、训练日志和项目进度说明。

## 🛠️ 核心修改说明 (针对 SinMDM)

| 修改文件 | 功能描述 | 解决的问题 |
|---|-|---|
| `model_util.py` | 动态调整输入层通道数 | 解决了原框架无法处理 263 维以外数据的崩溃问题 |
| `train_sinmdm.py` | 自动保存 `num_joints` 到 `args.json` | 确保训练后的模型在任何环境下都能正确载入维度信息 |
| `generate.py` | 优先读取模型元数据中的维度 | 彻底解决了生成阶段的维度不匹配报错 |
| `data_util.py` | 优化 `bvh_general` 加载器 | 实现了对敦煌舞原始 BVH 文件的直接读取，跳过繁琐预处理 |

## 🚀 快速开始

1. **环境准备**：克隆 SinMDM 官方仓库并安装依赖。
2. **应用修改**：将本仓库 `core_modifications/` 下的文件覆盖到 SinMDM 对应路径。
3. **推理/训练**：参考 `docs/system_technical_documentation.md` 中的命令。
